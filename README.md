## How to Run

Since this is a static website, you can simply open `index.html` in a browser.

### Option 1: Open directly
- Double-click on `index.html`, or
- Right-click and choose "Open with Browser"

### Option 2: Run with a local server
If you want to preview it locally through a simple HTTP server, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
